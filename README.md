## Run locally
 
No installation is needed.
 
```bash
git clone https://github.com/AANIYAMEHRA/aaniyamehra.github.io.git
cd aaniyamehra.github.io
```
 
Then open `index.html` in your browser. To use a local server instead:
 
```bash
python -m http.server 8000
# open http://localhost:8000
```
 
## Deploy and update
 
The site is published from the `main` branch (root folder) with GitHub Pages.
 
1. Edit `index.html` and commit the change to `main`.
2. GitHub Pages rebuilds automatically, and the update is live in about a minute.
3. To change the resume, replace `Aniya_Mehra_SDE_Resume.pdf` and keep the same file name.
